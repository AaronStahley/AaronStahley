# Aaron Stahley

Software engineer working with .NET, Azure, TypeScript/Next.js, Kubernetes and Go.

## Projects

**[Platform](https://github.com/AaronStahley/platform-gitops)**: an internal developer platform on Kubernetes, built as a proof of concept. Developers declare a small `WebApi` resource; a Go operator runs it, Argo CD syncs each environment from Git, and Kargo promotes changes dev → qa → prod.
Start with [platform-gitops](https://github.com/AaronStahley/platform-gitops) for the architecture, or [platform-bootstrap](https://github.com/AaronStahley/platform-bootstrap) to run it locally.
